# 意图契约 v1 —— lua-notify

## 项目目标

为 lua 库家族（lua_stb / lua_roaring / lua_sled / lua_webp / lua_statrs / lua_sysinfo）新增第 7 个成员 **lua_notify**：notify（Rust 跨平台文件系统通知库）的 Lua 5.4 绑定。

核心价值：补 Lua 生态"跨平台文件监控"空白（现有 linotify 仅 Linux）——一套 API 监听 Linux inotify / macOS FSEvents / Windows ReadDirectoryChangesW 的文件创建/修改/删除/重命名事件。与 lua_sysinfo 组成"状态 + 变化"完整可观测性。

关键设计约束：**poll 模式**（非回调、非阻塞迭代——Lua state 非线程安全，notify 回调线程绝不能调 Lua），事件在 Rust 侧 mpsc 队列累积，Lua 按自己的节奏取。

## 约束

- 模块模式：链接宿主 Lua（mlua 0.12 lua54 + module feature），不内嵌 VM，`require("lua_notify")` 可用
- 纯 Rust：依赖 notify crate（原生实现 inotify/FSEvents/ReadDirectoryChangesW），无额外 C 依赖
- 遵循家族模板：Cargo.toml（cdylib+rlib）、build.rs（macOS dynamic_lookup + pkg-config 测试链接）、Makefile（GNU toolchain on Windows）、CI（Linux/macOS/Windows + bench）、rockspec、README 中英、CHANGELOG
- 事件映射：EventKind 树形枚举拍平成稳定 Lua 字符串（如 "create/file"、"modify/data"、"remove/file"）
- 用户可见行为必须声明真实入口验证（ENTRY_LEVEL: real_user）——Lua 测试套件在真实目录上创建/修改/删除文件，poll 到对应事件
- 审计纪律：交叉审计发现的 panic 路径（NaN/Inf/边界）必须修复并补测试；mutants 变异测试收敛

## 技术栈入口

- 入口文件：src/lib.rs（mlua 0.12 + notify）
- 依赖版本：notify（最新稳定，探测实际 API：recommended_watcher + Watcher::watch + mpsc channel）
- 测试：tests/test.lua（真实目录事件）+ tests/lua_tests.rs（cargo test 内跑 Lua 套件）
- 构建：cargo +stable-x86_64-pc-windows-gnu（Windows GNU toolchain）

## Non-goals（不做）

- 不做回调式事件推送（跨线程 Lua 调用是 UB）
- 不引入 notify-debouncer-full（防抖留扩展，第一版只做核心 poll）
- 不打包 Lua 运行时（依赖宿主 Lua 5.4）
- 不做 Windows 长路径特殊处理（文档说明即可）

## 验收标准

- 所有任务完成后必须通过自审（verification.md）
- 置信度低于 0.7 的产出必须进入决策流
- 用户可见行为的产出必须声明真实入口验证（ENTRY_LEVEL: real_user）
- **功能**：watch(path, recursive) 建 watcher；poll() 非阻塞取事件（无事件返回 nil）；unwatch(path) 停止监听；事件含 kind 字符串 + paths 数组
- **测试**：tests/test.lua 在真实临时目录创建/修改/删除文件，断言 poll 到对应事件 kind；unwatch 后不再收到事件
- **质量**：交叉审计 + mutants 收敛（无可测缺陷存活）
- **发布**：CI 三平台绿（Linux/macOS/Windows + bench）+ GitHub release 资产
